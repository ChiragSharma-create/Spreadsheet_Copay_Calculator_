This project is a C++ program I built to solve a real-world problem. My aunt needed help calculating the total copay from an Excel spreadsheet, so I created a program that reads and processes CSV data to automate the calculation.

The program opens a CSV file, skips unnecessary header rows, and parses each remaining line using string streams. It extracts the relevant column containing copay values and converts the data into numeric form. To make the program more reliable, I added error handling to safely ignore invalid or missing data instead of crashing. The program then computes the total and outputs the final copay amount.

What I found most valuable in this project was applying what I learned in class to something practical. Instead of working with small test examples, I had to handle real data, which included inconsistent formatting and potential errors. This pushed me to think more carefully about edge cases and build a solution that could handle unexpected input.

Through this project, I developed:

Experience working with file input/output in C++
Skills in parsing and processing structured data (CSV files)
Understanding of error handling and data validation
Ability to apply programming concepts to real-world problems

This project reflects my interest in using programming to solve practical problems and automate tasks. It also shows how I can take concepts learned in class and apply them independently to build useful tools.
